# The source code for a paper Evaluation of a Method for Meta-Analysis of Studies with Complex Knowledge and Unexplained Heterogeneity: A Case Study of Down Syndrome Screening
Copyright (C) 2026 Martin Adamčík, e-mail: maths38@gmail.com  
The source code in the input.txt is to be run on the meta-analysis python package/program available either here on GitHub or on PyPI.
The code interpretation.py interprets probabilities obtained by the program in output.txt, and which are copied into probabilities.txt.
After running the program 25 times, each time removing one study, the range of interpreted values is specified in reliability.txt.
